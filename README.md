# ProTimer — イベントプログラムタイマー

学校・イベント・会議の進行を「時間割」で管理するスケジュール式タイマー。
ブラウザだけで動作し、PWAとしてホーム画面へのインストールやオフライン利用にも対応。

## 主な機能

- **時刻同期モード** — 現在時刻に合わせてスケジュールが自動進行。一時停止すると全体が繰り下がり、ズレ幅を常時表示
- **手動進行モード** — ボタン/キー操作で進行。時間切れ後は超過時間(+MM:SS)を赤表示。司会・発表会向け
- **進捗表示** — 現プログラムの進捗バー、全体進捗(n/N・%)、開始前カウントダウン
- **警告と音** — プログラムごとに「n分前警告」(点滅+音)と終了音を設定可能。音色は**チャイム / ベル / 電子音**から選択(警告=短く、終了=長く)
- **曜日別自動切替** — 曜日ごとにスケジュールを割り当てると、その日の時間割を自動で読み込み。日付が変わると自動で切替
- **初回ガイド** — はじめて開いた人向けの3ステップガイド(設定からいつでも再表示)
- **スケジュール編集** — ドラッグ&ドロップ並べ替え、行内編集、挿入、削除(元に戻す対応)、全消去
- **テンプレート** — 学校時間割・披露宴・セミナー・LT会・定期テスト・ポモドーロなど14種を同梱
- **共有** — URL/QRコードでスケジュール共有、JSONバックアップ、会場モニター用の閲覧専用URL
- **製品機能** — 画面スリープ防止(Wake Lock)、終了通知、音量設定、キーボードショートカット、オフライン動作(Service Worker)

## キーボードショートカット

| キー | 動作 |
|---|---|
| `Space` | スタート / 一時停止 |
| `←` `→` | 前へ / 次へ (手動進行モード) |
| `F` | 全画面切替 |
| `Esc` | 全画面・ダイアログを閉じる |

## 開発

ビルド不要の静的サイト構成 (`index.html` / `style.css` / `app.js` / `sw.js`)。
ローカル確認は任意の静的サーバーで:

```bash
python -m http.server 8741
```

アイコンの再生成: `Pillow` を入れて `make_icons.py` (別途) を実行。
